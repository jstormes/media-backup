Function key barcodes — F1 to F10

Scanning one of these makes the barcode scanner press that function key. MINJCODE MJ2818A (WoneNice WN3300 V3.1), HID keyboard wedge, no configuration required.

Rule: the barcode data is the single ASCII control byte 0x15 + n, encoded as Code 128. Every symbol below is verified machine-decodable.
